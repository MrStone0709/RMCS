## 2. 方法：注入通道与安全机制

### 2.1 为什么需要注入

生产配置下速度/角度环的参考由上层（角度环 / 自瞄）产生，**无法直接编程**。
因此新增注入组件，**在保持 `gimbal_controller` 在线**的前提下替换参考，
从而激励**真正的生产环路**（电机仍在**力矩模式**，`control_angle` 恒为 nan，
所以测到的是 `gimbal_controller` 的软件串级，不是电机内置环）。

### 2.2 三个注入组件（源码：`rmcs_ws/src/rmcs_core/src/identification/`）

| 组件 | 输出接口 | 语义 | 状态 |
|---|---|---|---|
| `VelocityReferenceInjector` | `/gimbal/yaw/velocity_command` | 速度参考（阶跃/扫频）| ✅ 主力 |
| `AngleReferenceInjector` | `/gimbal/yaw/angle_target_offset` | **目标角偏移**（阶跃/扫频）| ✅ 安全 |
| `AutoAimDirectionInjector` | `/auto_aim/control_direction` | 世界系绝对方向 | ❌ **已弃用（会失控）** |

### 2.3 各注入通道的安全性对比（重要）

| 通道 | 施加时风险 | 释放时风险 | 结论 |
|---|---|---|---|
| `SetControlDirection`（原自瞄路径）| ❌ 需已知世界朝向，**猜错 → 误差达 π → 全速冲** | ❌ 同样 | **弃用**（实测 8.52 rad/s 失控）|
| `yaw_shift` 速率注入 | ⚠️ 目标角**无限累积旋转** | — | 仅小速率可用 |
| **目标角偏移**（修复前）| ✅ 有界 | ❌ **偏移阶跃归零 → 云台高速回退**（`kp=35` 时 15.75 rad/s）| 已修 |
| **目标角偏移**（**修复后**）| ✅ 有界 | ✅ **斜坡淡出**，回退速度 ≤ `offset/ramp_down_s` | **采用** |

**修复实现**（`TwoAxisGimbalSolver::set_yaw_target_offset` +
`AngleReferenceInjector::ramp_down_s`）：

```cpp
// 求解器：偏移只对本拍误差计算有效，不进入累加状态
control_direction_ = cast<OdomImu>(yaw_link_to_pitch_link(dir_yaw, pitch), *tf_);  // 先存原始目标
if (yaw_target_offset_ != 0.0) { /* 绕 Z 旋转 yaw_target_offset_ */ }              // 再叠加偏移
return calculate_control_errors(dir_yaw, pitch);

// 注入器：结束时线性淡出而非阶跃归零
const double ramp_begin = event_end - hold_after_;
if (t_ >= ramp_begin) { command *= (1.0 - progress); }
```

**修复效果实测**（`yaw_angle_pid_compare/` 三组的 ramp 段速度峰值）：
`0.042 ~ 1.029 rad/s`，而修复前该段可达 **15.75 rad/s**。

### 2.4 激励与触发约定

- **触发**：`左中+右中`（idle）→ `左中+右上`（上升沿启动）；`左下+右下` 为急停
- **电机编号约定**（本报告统一）：**① 基准** = 原始生产配置；**② / ③ / ④** = 逐次调优

## 3. 系统辨识

### 3.1 被控对象定义

```
输入 u = /gimbal/yaw/control_torque   [N·m]
输出 y = /gimbal/yaw/velocity         [rad/s]
模型   G(s) = 1 / (J·s + B)           位置形式: 1 / (J·s² + B·s)
```

### 3.2 开环扫频实验（力矩激励，无 PID）

**实验条件**：对数扫频 0.15 → 20 Hz，时长 60 s，开环力矩激励。

| 数据集 | 幅值 | 组数 | 文件 |

### 3.3 辨识结论

#### ① J 是**最可靠**的辨识量

```
J ≈ 0.111 ~ 0.132 kg·m²（跨幅值、跨频段、跨方法）
最佳估计（**全带 0.3–3.0 Hz 拟合**）: J ≈ 0.1155 ~ 0.1223，组间 CV 2~4%

> ⚠️ **该值是"全带拟合"，混入了高频执行器滞后而偏大。**
> 驱动频段（0.5–1.0 Hz）的稳定值为 **J = 0.10** —— 见 [§3bis.3](#3bis3-j-的推导)。
```

**依据**：J 在所有拟合频段、两种激励幅值下稳定，是唯一不随工况漂移的参数。

#### ② B 是**频率相关 + 幅值相关**的等效阻尼

**幅值依赖**（同一台车、同一激励、仅改幅值）：

| 激励幅值 | B @0.3–1.0 Hz | B @0.3–3.0 Hz | 状态 |
|---|---|---|---|
| 1.0 N·m | 0.685 | 0.908 | 自由运动 |
| **0.8 N·m** | **0.983** | **1.129** | 自由运动 |
| 0.35 N·m | (≈2.5) | — | **静摩擦锁定** |

**频率依赖**（滑动频段，±1.0 N·m 5 组均值）：

| 频段 [Hz] | B | J |
|---|---|---|
| 0.30–0.80 | 0.714 | 0.131 |
| 0.80–1.30 | 0.843 | 0.115 |
| 1.50–2.00 | 0.940 | 0.117 |
| 3.00–3.50 | 1.076 | 0.130 |
| 6.00–6.50 | 1.392 | 0.166 | ← 相干度下降 |
| 8.00–8.50 | 4.629 | 0.229 | ← 不可用 |

**物理解释**：B 随幅值减小而增大、随频率升高而增大 → **库仑摩擦的典型特征**
（低速/小信号时干摩擦主导，等效线性阻尼变大）。
真正的**本征粘滞阻尼**应低于所有测量值，用户独立参考给出 **B ≈ 0.38**。

> ⚠️ **6 Hz 以上相干度崩溃，数据不可用**。所有结论只基于 0.3–3.0 Hz。

#### ③ 由辨识模型预测的环路指标（**已被闭环实测推翻，仅作记录**）

用 `G(s)=1/(0.1155s+0.932)` 与 `kp=13` 预测：

| `kp` | 穿越频率 | 相位裕度 |
|---|---|---|
| 13 | 17.9 Hz | 55° |
| 25 | 4.38 Hz | 22.1° |
| 40 | 7.01 Hz | 15.1° |

**实测为穿越 12.26 Hz、裕度 67.8°** —— 模型法偏保守/偏差，**以闭环实测为准**。

## 3bis. 最终辨识模型与推导过程

> ⚠️ **本节的部分结论已被 §3ter 推翻**（我在此用常数 B 逐频段拟合，方法不当）。
> **最终应采用 §3ter.5 的描述函数模型。** 本节保留以记录推导过程与教训。

> 本节给出**模型参数 `(J, B, Fc)`** 及其**每一步推导依据、原始数据来源、脚本**。

### 3bis.1 最终模型

```
             1                 dω     dθ
G(s) = ─────────── ,    J·─── + B·─── + Fc·sign(ω) = τ
         J·s + B_eff            dt     dt

  J        = 0.10  kg·m²            （转动惯量，最可靠）
  B_visc   = 0.38  N·m·s/rad        （本征粘滞阻尼）
  Fc       = 0.75  N·m              （库仑摩擦）
  B_eff(ω) = B_visc + Fc/|ω|        （等效线性阻尼，随速度变化）
```

**等价写法**（灰盒形式，与 `.script/identification/fit_sweep_graybox.py` 一致）：

```
J·θ̈ + B·θ̇ + Fc·tanh(k·θ̇) + G·sin(θ+φ) = τ
                ^^^^^^^^^^^^^^^^ k=100（本轴为滑环、无重力项，G=0）
```

### 3bis.2 参数置信度（重要）

| 参数 | 最佳估计 | 合理区间 | 置信度 | 主要来源 |
|---|---|---|---|---|
| **J** | **0.10 kg·m²** | 0.09 ~ 0.13 | **高** | 多频段、多幅值一致 |
| **B_visc** | **0.38 N·m·s/rad** | 0.30 ~ 0.50 | 中 | 极低频段 + 用户独立参考 |
| **Fc** | **0.75 N·m** | 0.6 ~ 0.9 | **中（本轴最难测量）** | 速度过零力矩 + 闭环稳态 |

⚠️ **`Fc` 不能从扫频数据标定** —— 见 3bis.5 的解释。

### 3bis.3 J 的推导

**方法**：开环扫频，频域相干加权最小二乘拟合 `1/H = B + jωJ`（`H` = 力矩→速度）。

**脚本**：`yaw_sweep/fit_yaw_final.py`、`yaw_sweep/fit_band_compare.py`（容器内 `python3`，需 numpy）

**逐频段结果**（`id_data/yaw_sweep/run*.csv` 5 组均值）：

| 拟合频段 | **J [kg·m²]** | B_eff | 备注 |
|---|---|---|---|
| 0.3–0.5 Hz | 0.061 ~ 0.090 | **0.362** | 加速度项 `Jω`（≈0.25）可忽略 → **B 最纯** |
| 0.5–1.0 Hz | **0.094 ~ 0.100** | 0.665 | J 已稳定 |
| 0.3–1.5 Hz | 0.092 ~ 0.105 | 0.565 | |
| 0.3–3.0 Hz | 0.119 ~ 0.131 | 0.656 | J 被抬高 |

`id_data/yaw_sweep_0.8Nm/run*.csv` 3 组均值：

| 拟合频段 | J | B_eff |
|---|---|---|
| 0.3–0.5 Hz | 0.018 ~ 0.065 | **0.960** |
| 0.5–1.0 Hz | **0.088 ~ 0.100** | 0.883 |
| 0.3–3.0 Hz | 0.123 ~ 0.135 | 0.856 |

**取值判断**：

- **`J` 在 0.5–1.0 Hz 频段稳定于 0.088~0.100**，跨幅值一致 → 取 **J = 0.10**
- 高频段 J 被抬高到 0.12~0.13，原因是**未建模的执行器滞后/电流环动态**被吸收进了 `jωJ` 项
  → 控制设计用的"驱动频段等效惯量"以 **0.10** 为宜
- 早期报告的 `J ≈ 0.1155~0.1223`（`0.3–3.0 Hz` 全带拟合）**偏大**，因为混入了高频段

> **为什么 J 最可靠**：它在**两种激励幅值、四个频段**下都落在 0.09~0.13 的窄区间，
> 是唯一不随工况漂移的参数（组间 CV 2~4%）。

### 3bis.4 B_visc 的推导

**关键洞察**：`B_eff` 随频率升高而增大（0.36 → 0.66），**不是**真正的粘滞阻尼变化，
而是**库仑摩擦的等效线性化项**。物理机理：扫频中**速度幅值随频率下降**
（`id_data/yaw_sweep/` 实测 `V_amp` 仅 **0.10~0.25 rad/s**），
而库仑摩擦的等效阻尼为

```
B_eff = B_visc + (2·Fc/π) / V_amp          （描述函数法）
```

V_amp 越小 → 等效阻尼越大。

**取值**：在**加速度项可忽略的最低频段 0.3–0.5 Hz**，得到

```
B_visc ≈ 0.362 (1.0 N·m 组)   ~   0.49 (0.8 N·m 组)
```

**与用户独立参考值 `B ≈ 0.38` 吻合** → 取 **`B_visc = 0.38 N·m·s/rad`**。

（对比：早期全带拟合给出 `B = 0.67~1.13`，那是把库仑摩擦的等效项一起算进去了。）

### 3bis.5 Fc 的推导（**本轴最难测的量**）

#### 方法 A：速度过零处的力矩 = 库仑摩擦

**原理**：`|τ| = Fc + B·|ω| + J·|α|`，当 `ω → 0` 时 `|τ| → Fc`（`B·ω` 项消失）。

**脚本**：`/tmp/friction.py`（本报告生成，逻辑：检测 `v` 符号变化，取过零点 ±2 ms 内 `|τ|` 均值）

| 数据 | 过零次数 | **Fc 均值** | Fc 中位 | CV |
|---|---|---|---|---|
| `yaw_sweep/`（±1.0 N·m）5 组 | 74~645 | **0.62 ~ 0.95** | 0.65~0.98 | 15~42% |
| `yaw_sweep_0.8Nm/`（±0.8 N·m）3 组 | 529~559 | **0.47 ~ 0.52** | 0.49~0.56 | 42~47% |
| **合计 8 组** | — | **0.64 ± 0.17** | — | 25.8% |

#### 方法 B：闭环稳态力矩（**最强的证据**）

**原理**：速度阶跃测试中每级平台速度恒定（`α ≈ 0`），故 `τ_ss = B·v_ss + Fc`。

**脚本**：`/tmp/grid.py`（本报告生成，对 `(B, Fc)` 做二维网格搜索）

30 个稳态平台（来自 `yaw_vel_step_pid_tuning/run1,run3,run4`、`yaw_ff_verify/*`）：

```
v_ss  ∈ [0.44, 2.50] rad/s
tau_ss ∈ [0.646, 0.928] N·m
tau 均值 0.798, 标准差 0.074,  corr(v, tau) = −0.397
```

**网格搜索最优解：`B = 0.00`, `Fc = 0.80 N·m`（R² = −0.0006）**

即：**力矩几乎与速度无关 → 库仑摩擦主导，粘滞项在此速度区间可忽略。**

#### 为什么 Fc 难以标定

| 数据集 | 速度区间 | 结论 |
|---|---|---|
| 开环扫频 | **0.10 ~ 0.25 rad/s**（幅值太小，轴几乎没动起来）| 只覆盖极低速 |
| 闭环稳态 | **0.44 ~ 2.50 rad/s** | 覆盖工作区间 |

**两个数据集覆盖的速度区间几乎不重叠**，而库仑摩擦的等效阻尼 `∝ 1/|ω|` 在低速区剧烈变化
→ **描述函数回归的约束很差**（本次回归 R² 仅 0.41，外推到无穷幅值才得到 `B_visc = 0.49`，
该外推已远离实测区间）。

**因此 Fc 采用方法 B 的直接结果，取 `Fc ≈ 0.75 N·m`（区间 0.6~0.9）。**

#### 模型自洽性检验

| 模型 | 对 30 个闭环稳态点的 RMSE |
|---|---|
| `B=0.00, Fc=0.80` | **0.072 N·m** ✅ |
| `B=0.35, Fc=0.75` | 0.616 N·m ❌ |
| `B=0.30, Fc=0.80` | 0.569 N·m ❌ |

**纯库仑模型（`B≈0`）在闭环工作区间内最自洽**；
但在**极低速区**（`|ω| < 0.3 rad/s`）粘滞项相对不重要、
`Fc·sign(ω)` 主导，此时用 `B_eff = B_visc + Fc/|ω|` 可统一描述两者。

### 3bis.6 模型的使用建议

| 用途 | 推荐形式 |
|---|---|
| **控制设计（驱动频段 0.5–3 Hz）** | `G(s) = 1/(0.10·s + B_eff)`，`B_eff` 取工作速度处的值 |
| **低速/摩擦补偿** | `τ_ff = Fc·sign(ω_des) + B_visc·ω_des + J·α_des` <br> 用 `Fc=0.75, B_visc=0.38, J=0.10` |
| **频率响应预测** | 用 `G(s)=1/(0.10s+0.38)` → 转折 0.6 Hz；与实测闭环带宽 18.1 Hz 的对比见 §4.1 |
| ⚠️ **不要** | 用 `J=0.1223` 去设计高带宽环（含未建模滞后，会高估相位）|

#### 与前馈推荐值的关系

§7.1 推荐 `yaw_velocity_ff_gain = 0.29`、`yaw_acceleration_ff_gain = 0.115`：

- **`0.115`（≈J）现已修正为 `0.10`** —— 依据是本次 J 的重新推导（0.5–1.0 Hz 频段）
- `0.29` 保留（高速工作点等效阻尼；本模型下宜取工作速度处的 `B_eff`）

## 3ter. ⚠️ 关于模型版本的重要更正

> **本节修正 §3bis。** 在 §3bis 里我给出了与**先前模型不一致**的一套参数，
> 且没有说明二者关系 —— 这是错误的做法。本节交代清楚。

### 3ter.1 两套参数

| 版本 | 形式 | 参数 |
|---|---|---|
| **先前（灰盒，正确形式）** | `B_eff = B_visc + K·√(B_eff² + (Jω)²)/A`，`K = 2Fc/π` | `J = 0.1155`, `B_visc = 0.70`, `Fc = 0.31`，残差 **5~8%** |
| §3bis（我后来的"重估"） | 常数 `B` 的 `G(s)=1/(Js+B)` | `J = 0.10`, `B_visc = 0.38`, `Fc = 0.75` |

### 3ter.2 我那次"重估"的三个问题

| # | 问题 | 说明 |
|---|---|---|
| 1 | **用常数 B 逐频段拟合** | 描述函数的核心恰恰是 **B 随 `A` 和 `ω` 变化**；假设每频段内 B 为常数，就把该变化"摊"进了各频段的 B 和 J，导致 **J 随频段漂移**（0.09 → 0.13）——**这个漂移是模型不适配的症状，不是物理** |
| 2 | **把低频段的 B=0.36 当成 `B_visc`** | 低频段实测 `B_eff` 里**仍含库仑贡献** `K·√(B_eff²+(Jω)²)/A`，不能直接等同 `B_visc` |
| 3 | **残差更高却未察觉** | 常数 B 拟合残差 **16~19%**；灰盒 **5~8%**。**残差更低的形式才是更好的模型** |

**结论：先前那套（描述函数形式）在形式上正确、残差更低，应当采用。**

### 3ter.3 对 Fc 的独立检验（**存在仍未解释的偏差**）

用**速度过零精确定位**（线性插值到 `v=0`）测 `|τ|`，理论上 `|τ| → Fc`：

| 数据 | 过零点数 | \|τ\|@v=0 均值 | 中位 |
|---|---|---|---|
| `yaw_sweep/`（±1.0 N·m）| 1966 | **0.6562** | 0.6790 |
| `yaw_sweep_0.8Nm/`（±0.8 N·m）| 1629 | **0.4904** | 0.5184 |

| 版本 | Fc | 与过零实测（0.49~0.66）比较 |
|---|---|---|
| 先前灰盒 | **0.31** | 偏低约 0.2~0.35 |
| §3bis | 0.75 | 偏高 |
| **过零实测** | **0.49 ~ 0.66** | — |

**建议 `Fc ≈ 0.5 N·m`** —— 但**必须说明**：过零处 `α` 并不严格为零，
且电机内环有滤波延迟，所以这个估计**有系统偏差**，`Fc` 仍是三个参数里最不确定的。

### 3ter.4 闭环稳态力矩的"反常"（**与本模型不符，未解释**）

闭环速度阶跃的稳态力矩（速度恒定 → 无加速度项）**几乎与速度无关**：

| 速度分箱 | v 均值 | **τ 实测均值** |
|---|---|---|
| [0.4,0.7) | 0.486 | 0.883 |
| [0.7,1.2) | 0.987 | 0.776 |
| [1.2,1.8) | 1.488 | 0.815 |
| [1.8,2.2) | 1.989 | 0.750 |
| [2.2,2.6) | 2.489 | 0.783 |

**任何 `B·v + Fc`（B>0）都预测力矩随速度上升**：

| 参数 | RMSE（对 30 个稳态点）|
|---|---|
| `B=0.70, Fc=0.31`（先前）| 0.870 N·m |
| `B=0.38, Fc=0.75`（§3bis）| 0.663 N·m |
| `B=0, Fc=0.80`（纯库仑）| **0.073 N·m** |

**这是本报告最大的未解之谜**：开环扫频明确显示存在粘滞阻尼（低速幅值下 `B_eff ≈ 0.4~0.9`），
但闭环稳态力矩却几乎不随速度变化。

**可能原因（未验证）**：
- 电机内速度环的动态/滤波使 `/gimbal/yaw/torque` 反馈与瞬时力矩不同步
- 该反馈量的标定/延迟在闭环与开环两种工况下表现不同
- 轴在闭环低速工况下存在与开环不同的摩擦状态（如润滑膜状态差异）

**因此：不要把"闭环稳态力矩"当作摩擦参数的标定依据，应以开环扫频 + 描述函数为准。**

#### ② 积分限幅是"隐藏约束"

诊断日志（`[DIAG-VEL]`）在 `ref=2.5 rad/s` 稳态时：

```
ref=2.5  v_imu=2.50025  err=-0.00025  pid_out=0.74672  (kp*err=-0.00328)  total=0.74672
```

`pid_out` 几乎全部来自积分项，即 `pid_out = ki·I → 0.74672 = 0.5·I → I = 1.487 ≈ 限幅 1.5`。
**积分已饱和**，速度再高给不出更多力矩 → 残留稳态误差。
放宽到 ±2.5（输出上限 `0.5×2.5 = 1.25 N·m`，远低于电机能力）后误差降到 `2×10⁻⁵`。

> **注意这是"限幅"不是"增益"**：放宽限幅不会像提高 `ki` 那样引入超调。

#### ③ `integral_split` 是陷阱（若设得过窄）

`PidCalculator::update()` 的实现：

```cpp
if (err < integral_split_max && err > integral_split_min) { 累积积分 }
else { err_integral_ = 0; }        // ← 误差超限就把积分清零
```

曾设 `split = ±1.0`，结果阶跃瞬态的大误差**反复清零积分**，积分无法累积 →
与 `ki=0.02` 相比只改善 4%。放宽到 ±3.5 后正常。

## 6. 前馈验证

### 6.1 前馈的生效条件（**关键**）

源码 `trajectory_feedforward()`：

```cpp
if (!auto_aim_active || !input_.auto_aim_ff_v.ready() || !input_.auto_aim_ff_a.ready()
    || !input_.auto_aim_ff_v->allFinite() || !input_.auto_aim_ff_a->allFinite())
    return {};                       // 不满足则整组返回 0

// auto_aim_active = (鼠标右键 || 右开关 UP)
//                   && /auto_aim/should_control && /auto_aim/control_direction 就绪
```

**两重门**：

| 工况 | 前馈 |
|---|---|
| 手动（右开关 MIDDLE）| ❌ 完全不生效 |
| 右开关 UP 但 `AutoAimComponent` 未运行 | ❌ **不生效**（`ff_v`/`ff_a` 未就绪）|

**接口类型必须是 `Eigen::Vector3d`**（世界系方向向量，取 `.z()` 为 yaw 分量）。
注册成 `double` 会让执行器以
`Type mismatch for Normal interface "/auto_aim/ff_v"` **FATAL 退出**（本次踩过）。

### 6.2 验证方法（方案 C）

让 `VelocityReferenceInjector` **发布 `/auto_aim/ff_v` 与 `/auto_aim/ff_a`**
（新增 `enable_feedforward` 开关），从而**在不启用 `AutoAimComponent` 的情况下**
激活前馈通道。为干净隔离力矩通道，把 `yaw_ref_velocity_gain` 设为 0。

```
ff_v = ω_ref                       (rad/s)
ff_a = dω_ref/dt 经 20 Hz 一阶滤波 (rad/s²)
gimbal_controller: torque += yaw_velocity_ff_gain·ff_v.z()
                          + yaw_acceleration_ff_gain·ff_a.z()
```

**激励（两组一致）**：与速度环调优相同的 5 级阶梯 `0.5→3.0 rad/s`，每级 5 s。

**数据来源**：

| 组 | `yaw_velocity_ff_gain` | `yaw_acceleration_ff_gain` | `enable_feedforward` | 文件 |
|---|---|---|---|---|
| 基线 | 0.0 | 0.0 | false | `yaw_ff_verify/baseline_nofeedforward.csv` |

### 6.3 结果（本次从原始 CSV 重算）

| ref | **基线 稳态 v** | **前馈 ON 稳态 v** |
|---|---|---|
| 0.5 | 0.5003 | 0.5002 |
| 1.0 | 0.9997 | 0.9997 |
| 1.5 | 1.5000 | 1.5003 |
| 2.0 | 1.9999 | 1.9997 |
| 2.5 | 2.5001 | 2.4998 |
| **误差均值** | **+0.00002** | **+0.00004** |

| 指标 | 基线 | 前馈 ON |
|---|---|---|
| 速度峰值 | 2.621 rad/s | 2.614 rad/s |
| 力矩峰值 | 7.61 N·m | 7.52 N·m |
| 稳态力矩 | 0.71~0.84 N·m | 0.73~1.01 N·m |

### 6.4 结论：**速度工况下前馈无可测收益**

**原因**：前馈的贡献是 `0.29·ω_ref`（0.145 N·m @0.5 rad/s；0.725 N·m @2.5 rad/s），
但**反馈环已经把这个活干完了** —— 速度环调优后稳态误差仅 `0.0003 rad/s`，
积分提供的力矩（0.71~0.84 N·m）正好匹配所需力矩。

**闭环力矩分解**（`ref=2.5`）：
```
总力矩 = 前馈 + kp·err + ki·∫err
       = 0.725 + 13×0.0003 + 0.71  ≈ 1.44  ← P 项只需 0.004！
```
**积分几乎独自承担全部稳态力矩且完全够用**，前馈补多少都不改变结果。

#### 前馈真正有用的场景（本测试未覆盖）

| 场景 | 原因 |
|---|---|
| 积分限幅更紧（如 ∓1.0）| 积分不够用时前馈补足 |
| **大幅快速机动（自瞄跟踪）** | 瞬态时反馈来不及，前馈提前给力矩 |
| `kp` 很低的环路 | 反馈增益小，前馈承担更多 |

#### ⚠️ 顺带发现的真实风险

测试中 `ff_a` **峰值达 59.04 rad/s²**（而 `ff_v` 仅 0.5~2.5）：

```
ff_a ≈ (0.5 rad/s) / (1 ms) × 滤波 = 大值
```

若启用 `yaw_acceleration_ff_gain = 0.115`，会额外产生 `0.115 × 59 ≈ 6.8 N·m` 的尖峰。
**说明 `ff_a` 必须有充分低通滤波**，否则阶跃型参考会激发力矩尖峰。
（真实自瞄的 `ff_a` 来自平滑的目标运动，量级应远小于本测试的人为构造。）

## 9. 已知偏差、异常与教训

### 9.1 辨识的已知偏差

| 项 | 说明 |
|---|---|
| **B 不确定** | 0.598~1.184（跨方法/频段/幅值），**不是一个常数**。本征粘滞阻尼估计 `≈0.38`（用户独立参考）|
| **模型法预测 PM 不准** | 模型预测 55°，闭环实测 **67.8°** → **以实测为准** |
| **时域参数拟合不可靠** | `τ = J·a + B·v + Fc·sign(v)` 全点最小二乘给出 **B 为负**（R²=0.34），因加速度由陀螺微分、噪声主导 |
| **高频（>6 Hz）数据不可用** | 相干度崩溃；>`20 Hz` 因力矩饱和失真 |
| **早期 `J ≈ 0.1155~0.1223` 偏大** | 那是 `0.3–3.0 Hz` 全带拟合值，混入了高频执行器滞后；**驱动频段应为 0.10**（§3bis.3）|
| **`Fc` 无法从扫频标定** | 扫频速度幅值仅 0.10~0.25 rad/s，与闭环工作区间（0.44~2.5）几乎不重叠（§3bis.5）|

### 9.2 温度读数异常（**未解决**）

`yaw_angle_pid_compare/` 与 `yaw_ff_verify/` 的 CSV 中
`/gimbal/yaw/temperature` **恒为 125.0**（22000 样本零变化）。

- `125 = int8_t` 最大值 → 疑为**哨兵值 / CAN 温度反馈异常**
- 代码：`temperature_ = static_cast<double>(feedback.temperature);`
- **判断：不是真实过热**（全程力矩仅 −0.09~−0.78 N·m）
- **对比**：早期测试（`yaw_vel_*`）温度正常，为 34~40 °C 且随负载变化

### 9.3 分析方法论教训（**重要**）

| 教训 | 具体事故 |
|---|---|
| **对比实验必须先确认激励时序** | 曾假定阶跃在 t=2/7/12…，实际在 6/11/16/21，于是"稳态窗口"落在**阶跃前的平台**上，把**阶跃量 0.5 rad/s 误读为稳态误差**，得出"误差与 `ki` 无关"的错误结论 |
| **不要用单点观测反推坐标系常量** | `angle_offset_rad=0.886` 从一次观测反推，换角度即失效 → **云台失控高速旋转**（8.52 rad/s）|
| **注入偏移必须设计"释放"过程** | 目标角偏移若阶跃归零，云台会高速回退（`kp=35` 时 15.75 rad/s）。**必须斜坡淡出** |
| **执行器接口类型必须核对** | `/auto_aim/ff_v` 是 `Eigen::Vector3d` 而非 `double`，类型不符会 FATAL |
| **执行器依赖边包含 required=false** | 注入器读被注入对象的输出 → `Circular dependency found` FATAL |
| **输出必须在构造函数体注册** | 在 `before_pairing` 注册的输出不进 `output_map`，消费方 `find` 失败且**静默跳过**（`ready()` 永远 false、无日志）|
