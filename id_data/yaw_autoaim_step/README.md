# 云台 yaw 「目标角阶跃」测试（自瞄路径注入）

## 为什么走自瞄路径

`DeformableInfantryGimbalController` 有两条控制路径：

| 路径 | 实现 | 目标角特性 |
|---|---|---|
| 手动（摇杆/鼠标）| `SetControlShift{yaw_shift, pitch_shift}` | **速率式** —— 目标角以 shift 为速率**累积成斜坡** |
| **自瞄** | `SetControlDirection{绝对方向}` | **直接给定绝对目标方向**，方向跳变即目标角**阶跃** |

自瞄真实工况下目标角确实会出现锯齿/跳变（目标切换时），所以**阶跃测试是必要的**，
不能用斜坡替代。

而 `SetControlDirection` 的输入 `/auto_aim/control_direction` 是**已有的公开接口**，
因此本方案**完全不需要修改 gimbal_controller**（零侵入），只新增了
`AutoAimDirectionInjector` 组件扮演自瞄数据源。

## 方向向量的构造

求解器算 yaw 误差：`yaw_angle_error = std::atan2(y, x)`（YawLink 系）。要设定目标
yaw 角 ψ，方向取

```
dir = ( cos ψ · cos θ,  sin ψ · cos θ,  sin θ )      θ = pitch_target_
```

- **θ = 0（`pitch_target: 0`）**：退化为 `(cos ψ, sin ψ, 0)`，**目标 pitch 保持水平**
  → pitch 误差≈0，**刻意让 pitch 不参与**（早期用 yaw_shift 持续旋转时曾把 pitch
  甩偏并引发 pitch 锁点高频抖动，此设计避免了它）
- ⚠️ `(cos ψ, 0, sin ψ)` 是**错的** —— 会得到 `yaw_error = atan2(0, x) = 0`，不产生任何 yaw 指令

## 关键：编码器角与世界系角的固定偏移

`/gimbal/yaw/angle` 是**电机编码器角** ψ_meas，而求解器用**世界系** YawLink 角 ψ_true，
二者相差一个固定量 μ：

```
ψ_true = μ + ψ_meas
```

发方向 ψ_cmd 后误差 = ψ_cmd − ψ_true，角度环 kp=10 驱动云台。实测该闭环的
**系统增益为 2**，稳定点满足 `2·ψ_cmd − ψ_solver = μ`。

**因此要零误差，目标必须取 `ψ_cmd = ψ_meas + μ`。**

μ 由实测标定：把方向设为 +ψ_meas 时，云台停在 ψ_meas+0.886 —— 故 **μ ≈ 0.886 rad**，
以 `angle_offset_rad` 参数注入。

### 走过的弯路（记录以免重犯）

| 尝试 | 结果 | 原因 |
|---|---|---|
| 给**角误差**叠加偏移 | 卡住不动 | 求解器误差按实际角实时算，云台一动误差即减，`solver_err ≈ −offset`、净误差≈0 |
| 用 **yaw_shift 恒速率**持续旋转 | 失控（±4 rad/s、±11 N·m）| 目标角**无限累积旋转**，非有界阶跃；且甩动 pitch |
| 目标 = **实测角 + Δ** | 0.4 s 内冲 0.9 rad | 云台一动、下一拍目标又前移 Δ → **目标永远跑在前面**，退化为持续旋转 |
| 目标 = **−实测角** | 同样失控 | 方向等价（cos/sin 2π 周期），未解决偏移 |
| **目标 = 实测角 + μ** | ✅ 成功 | 正确补偿了坐标系偏移 |

## 实验配置（三轮共用）

```yaml
autoaim_injector:
  ros__parameters:
    angle_offset_rad: 0.886     # 编码器角 -> 世界系角偏移（实测标定）
    settle_s: 3.0               # 触发后等初始偏转完成
    hold_before_s: 1.0          # 第 0 级基准
    step_count: 4
    step_delta: 0.05 / 0.15 / 0.25
    step_hold_s: 5.0
    pitch_target: 0.0           # pitch 保持水平
    angle_limit: 0.60 / 0.90 / 1.40
```

时序：`settle 3s → 基准 1s → N 级 × 5s`（每级一次**真正的目标角阶跃**）。

**gimbal_controller 参数零改动**（纯生产配置）。

## 三轮对比与结论

| | 0.05 rad/级 | 0.15 rad/级 | **0.25 rad/级** |
|---|---|---|---|
| 增益 | 0.82~0.85 | 0.91~0.95 | **0.974~0.986** |
| 超调 | 2.5~7.6% | 0.6~0.9% | **0.4~1.5%** |
| 上升 | ~180 ms | — | **~207 ms** |
| pitch 跨度 | 0.0012 | 0.0035 | **0.0116 rad** |
| 温度 | 34→34 | 35→35 | **35→35 °C** |

**结论：**

1. **跟踪增益随阶跃幅值增大而提高**（0.83 → 0.98）。符合机理：库仑摩擦死区
   （≈0.025 rad）在幅值中的占比随幅值增大而减小。
2. **上升时间 ~180~210 ms、超调 <2%** —— 阻尼充分、快速且稳定，**无极限环**。
3. **稳态误差 0.004~0.006 rad** —— 就是库仑摩擦死区，与速度环的独立分析一致。
4. **pitch 始终安静**（跨度 ≤0.0116 rad）—— `pitch_target=0` 的设计奏效。
5. **温度完全稳定**（20+ 秒测试内不升）。

**当前 yaw 角度控制在 0.25 rad 阶跃下表现优秀，不需要激进调整。**

## 硬件边界

| 项 | 0.15 rad/级 | **0.25 rad/级** |
|---|---|---|
| yaw 力矩峰值 | +11.20 N·m | **±11.31 N·m** |
| yaw 力矩 rms | 0.876 | 1.241 |
| yaw 速度 rms | 0.327 | 0.623 |

**力矩峰值正好顶在观测到的电流上限 11.29 N·m** —— 说明 0.25 rad 阶跃已是
"能快速完成"的边界。**继续放大将进入持续饱和区**，表现为阶跃变慢、增益下降
（限幅非线性），而非线性变差。
