# yaw 速度环 PID 调优记录（四组对比）

## 实验方法

**注入方式**：`VelocityReferenceInjector` 直接替换 yaw 速度环参考
（`gimbal_controller` 的 `yaw_velocity_command_input: true`），
**保持 gimbal_controller 在线**，因此测到的是**真正的生产速度环**。
电机仍处于**力矩模式**（`control_angle` 恒为 nan）。

**激励**（四组完全一致，可直接逐平台对比）：

```
预载 0.5 rad/s ──7s── 1.0 ──5s── 1.5 ──5s── 2.0 ──5s── 2.5 ──5s── 3.0
   平台0                平台1      平台2      平台3      平台4      (截断)
```

- `step_from: 0.5`、`step_count: 5`、`step_delta: 0.5`、`step_hold_s: 5.0`
- 实测阶跃时刻：**t = 7.0 / 12.0 / 17.0 / 22.0 / 27.0 s**

列：`update_count, elapsed_s, velocity_reference, /gimbal/yaw/velocity_imu,`
`/gimbal/yaw/velocity, /gimbal/yaw/torque, /gimbal/yaw/angle, temperature, max_torque`

## ⚠️ 分析方法上的重要更正

**首轮分析曾得出"稳态误差恒定 0.5 rad/s，与参考无关，且与积分增益无关"的结论 —— 那是错的。**

原因：我**没有先验证阶跃时刻**就假定阶跃发生在 t = 2/7/12/17/22，于是"稳态窗口"
恰好落在**阶跃前的平台**上，把**阶跃量本身（0.5 rad/s）**误读成了稳态误差。

**正确做法**：从数据中检测 `velocity_reference` 的跳变时刻（四组都是 7/12/17/22/27），
再取**各平台末 1.5 s** 作为稳态窗口。

> 教训：对比实验必须先确认激励时序，再固定分析窗口。

## 汇总

| 配置 | 误差均值 | 最大误差 | 跟踪率 | 超调 | 力矩峰 | 温度 |
|---|---|---|---|---|---|---|
| ① 基准 `ki=0.02` | +0.05563 | 0.06342 | 94.68% | +13.30% | 7.06 N·m | 35→35 °C |
| ② 坏调 `ki=2.0` | +0.02931 | 0.03205 | 97.32% | **+55.66%** | 10.56 N·m | 35→35 °C |
| ③ `ki=0.5` ±1.5 | +0.00505 | 0.00861 | 99.51% | +10.92% | 7.09 N·m | 35→35 °C |
| **④ `ki=0.5` ±2.5** | **+0.00002** | **0.00037** | **99.99%** | +15.94% | 7.25 N·m | 35→35 °C |

超调 = 各次阶跃 `(峰值 − 稳态) / 阶跃量` 的平均值。

## 结论

### 1. ① → ④：稳态误差改善 99.96%

```
误差均值  0.05563 -> 0.00002 rad/s
跟踪率    94.68%  -> 99.99%
力矩峰值  7.06    -> 7.25 N·m   （基本不变，未饱和）
温度      35->35  -> 35->35 °C  （稳定）
```

### 2. ② 的振荡根因：超调 55.66%

`ki=2.0` 时阶跃超调高达 **55.66%**，表现为现场观察到的
**"双中档位 yaw 小幅高频左右晃动"**。同时力矩峰值顶到 **10.56 N·m**（接近电流上限 11.29）。

**`ki` 过大是振荡的直接原因，与积分限幅无关。**

### 3. 积分限幅是关键的"隐藏约束"

**诊断数据**（`[DIAG-VEL]`）显示，维持 2.5 rad/s 时：

```
ref=2.5  v_imu=2.50025  err=-0.00025  pid_out=0.74672  (kp*err=-0.00328)  total=0.74672
```

`pid_out` 几乎全部来自积分项（比例项仅 −0.003），即

```
pid_out = ki * I   ->   0.74672 = 0.5 * I   ->   I = 1.487  ≈ 限幅 1.5
```

**积分已经饱和。** 速度再高就无法提供足够力矩 → 残留稳态误差。
放宽到 ±2.5 后（输出上限 0.5×2.5 = 1.25 N·m，远低于电机能力）误差降到 2×10⁻⁵。

**注意这是"限幅"不是"增益"**：放宽限幅不会像提高 `ki` 那样引入超调，
因为输出上限仍由电机能力兜底。

### 4. 权衡：超调略增

| | ③ ±1.5 | ④ ±2.5 |
|---|---|---|
| 稳态误差 | 0.00505 | **0.00002**（好 250 倍）|
| 超调 | +10.92% | +15.94% |

用 **5% 的超调**换 **250 倍**的稳态精度。若更在意超调，可折中到 ±2.0。

## 推荐配置（当前生产配置）

```yaml
yaw_velocity_kp: 13.0
yaw_velocity_ki: 0.5
yaw_velocity_kd: 0.0
yaw_velocity_integral_min: -2.5
yaw_velocity_integral_max: 2.5
yaw_velocity_integral_split_min: -3.5
yaw_velocity_integral_split_max: 3.5
```

### 各值的依据

| 参数 | 值 | 依据 |
|---|---|---|
| `kp` | 13.0 | 速度环**实测开环相位裕度 67.8°**（穿越 12.26 Hz），健康，无需改动 |
| `ki` | 0.5 | ①(0.02) 误差 0.056；②(2.0) 超调 56% 振荡；0.5 兼顾两者 |
| `kd` | 0.0 | 反馈为 IMU 陀螺，微分放大噪声；超调已 <16%，不需要 |
| 积分限幅 | ±2.5 | 消除"积分饱和"这一隐藏约束（见结论 3） |
| 积分分离 | ±3.5 | 原缺省为 ±inf；实测 ±1.0 会因阶跃瞬态反复清零积分而失效 |

### 关于相位裕度的实测来源

由速度环闭环频响 `T(f) = v_imu / v_ref` 反推开环 `L = T/(1−T)`：

| f [Hz] | \|L\| | 相位 [deg] |
|---|---|---|
| 7.08 | 2.23 | −100.0 |
| 10.99 | 1.27 | −108.6 |
| **12.26** | **1.00** | **−112.2** |
| 12.94 | 0.89 | −113.9 |
| 18.07 | 0.51 | −127.0 |

→ 穿越 12.26 Hz，**相位裕度 ≈ 67.8°**
