# 云台 yaw 速度环「参考注入」阶跃测试

## 实验意义

生产配置下 yaw 速度环的参考由角度环产生，无法直接编程。本次通过新增的
`VelocityReferenceInjector` 组件，在**保持 gimbal_controller 在线**的前提下
直接替换速度参考，从而激励**真正的生产速度环**。

## 配置

```yaml
gimbal_controller:
  yaw_control_enabled: true           # 保持在线（不要设为 false，那是让出控制权）
  yaw_velocity_command_input: true    # 打开速度参考注入

yaw_vel_injector:
  step_enabled: true
  step_from: 0.5                      # 预载，脱离静摩擦
  step_to: 3.0                        # 阶跃目标 rad/s
  hold_before_s: 1.0
  hold_after_s: 2.5
```

电机仍工作在**力矩模式**（control_angle 恒为 nan），所以测到的是 gimbal_controller
的软件串级（角度环→速度环），不是电机内置环。

## 关键观察

1. **速度环是健康且快速的**：上升时间 28 ms、超调仅 0.5%，说明按辨识模型算出的
   17.9 Hz 穿越频率是合理的。

2. **稳态误差 +2.4%，且稳态力矩已达 1.03 N·m**（电机额定 4.5 N·m、我们标定的
   连续工作点约 1.16 N·m）。也就是说维持 2.93 rad/s 已经需要接近满力，
   **`yaw_velocity_ki = 0.02`（时间常数 50 s）的积分太弱，补不上这个差额**。
   这印证了「应提高积分增益」的判断。

3. **等效阻尼随速度强烈变化**（库仑摩擦主导低速）：
   | 速度 | tau/v |
   |---|---|
   | 0.44 rad/s | 2.147 N·m/(rad/s) |
   | 2.93 rad/s | **0.318 N·m/(rad/s)** |

   低速时等效阻尼是高速时的 6.7 倍 —— 这正是库仑摩擦 `Fc/V` 的特征，
   也解释了为什么之前的低频扫频给出偏大的 B。

4. **跃变瞬间力矩冲到 ~11 N·m**（远超额定，接近峰值 11.29 N·m 观测上限），
   随后 40 ms 内回落到 1 N·m 量级 —— 说明电机确实有充足峰值能力可用。

## 时域参数拟合不可靠

用 `tau = J*a + B*v + Fc*sign(v)` 对全点做最小二乘：
```
J=+0.0475  B=-0.0456  Fc=+1.060  R^2=0.342   <- B 为负，无效
```
原因是加速度 `dv/dt` 由陀螺速度数值微分得到，噪声主导（与之前扫频分析的
结论一致）。**参数辨识仍应走频域法，不要用这条路径。**
