## 辨识结果（相干加权最小二乘，0.3–3.0 Hz）

    G(s) = 1 / (J*s + B)          位置形式: 1 / (J*s^2 + B*s)

    J = 0.1223  +/- 0.0025  kg*m^2       (组间 CV 2.1%)
    B = 0.908   +/- 0.053   N*m*s/rad    (组间 CV 6.0%)
    转折频率 = 1.18 Hz
    时间常数 = 134.7 ms
    拟合残差 = 6~9%

频率分辨率无关性（三种 NFFT 结果一致）：
    NFFT=8192  -> B=0.9078  J=0.12231
    NFFT=16384 -> B=0.9087  J=0.12302
    NFFT=32768 -> B=0.9053  J=0.12307

J 在 0.3–4.5 Hz 稳定于 0.115–0.132；B 随频率单调上升（0.71–1.08），
说明它是频率相关的等效阻尼（含库仑摩擦的等效线性化成分）。
6 Hz 以上相干度崩溃，数据不可用。

## 控制含义（基于 J=0.1223, B=0.908）

生产速度环 kp=13, ki=0.02：
    穿越频率 ~ 2.28 Hz，相位裕度 ~ 36.5°

候选增益：
    kp=13 -> 2.28 Hz, 36.5°
    kp=25 -> 4.38 Hz, 22.1°
    kp=40 -> 7.01 Hz, 15.1°

## 已知偏差

参考实验给出 B ~ 0.38，本辨识为 0.908（差 2.4 倍）。
可能原因：B 是频率相关量；参考值可能在不同激励幅值/速度区间测得，
或使用了不同的信号对（如实测力矩 vs 命令力矩）。
0.3–0.8 Hz 频段单独拟合给出 B = 0.71，与 0.38 更接近。
