## 关键发现：B 同时依赖幅值和频率

同一台车、同一激励、仅改幅值：

| 幅值 | B @0.3–1.0 Hz | B @0.3–3.0 Hz | 状态 |
|---|---|---|---|
| 1.0 N·m | 0.685 ± 0.096 | 0.908 ± 0.053 | 自由运动 |
| **0.8 N·m** | **0.983 ± 0.008** | **1.129 ± 0.011** | 自由运动 |
| 0.35 N·m | (≈2.5) | — | 静摩擦锁定 |

B 随幅值减小而增大 —— 这是**库仑摩擦的典型特征**：
低速时干摩擦在 yaw 轴上占主导，等效线性阻尼变大。

（注：0.6 N·m 曾出现"一次动、一次不动"的不稳定，说明摩擦锁定边界在 0.6 N·m 附近）

## 控制含义（J=0.112, B=0.983 @0.3–1.0 Hz）

    穿越频率 ≈ 2.11 Hz，相位裕度 ≈ 38.0°

    kp=13 -> 2.11 Hz, 38.0°
    kp=25 -> 4.05 Hz, 22.0°
    kp=40 -> 6.49 Hz, 14.5°

## 与参考值 B≈0.38 的关系

参考实验 0.38 < 本次所有测量值。趋势外推：B 随幅值增大而减小，
1.0 N·m 时最低频段（0.3–1.0 Hz）为 0.685 —— 仍高于 0.38。
若参考值在更大幅值或更高速度区间测得，则 0.38 可能更接近本征粘滞阻尼，
而本次测得值包含了库仑摩擦的等效贡献。
