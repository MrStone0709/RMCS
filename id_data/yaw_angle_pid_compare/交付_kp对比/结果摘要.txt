yaw 角度环 PID 对比 —— 结果摘要
======================================================
激励：0.15 rad 阶跃，每级 5 s（3 级），同注入方法同速度环

配置           A: kp=10      B: kp=15      C: kp=35 ki=0.5
                 ki=0          ki=0
------------------------------------------------------
增益            0.962         0.956         0.953
超调            +3.2%         +3.8%         +84.5%   <-- C 严重
上升时间        204 ms        135 ms         43 ms
整定时间        268 ms        184 ms        274 ms
稳态误差        +0.0058       +0.0065       +0.0070
速度峰值        1.566 rad/s   2.126 rad/s   4.641 rad/s
力矩峰值        11.26 N·m     11.35 N·m     11.36 N·m
pitch 跨度      0.0021 rad    0.0017 rad    0.0022 rad
------------------------------------------------------

结论：B (kp=15, ki=0) 优于 A (kp=10, ki=0)
  - 上升时间快 34%（204 -> 135 ms）
  - 整定时间快 31%（268 -> 184 ms）
  - 超调几乎不变（3.2% -> 3.8%）
  => 净收益，推荐保留 kp=15 / ki=0 / kd=0

C (kp=35, ki=0.5) 的问题：
  - 超调 84.5%（每次阶跃都过冲再拉回）
  - 整定时间 274 ms，反而比 B 的 184 ms 更慢
  - 速度峰值 2.96 倍，力矩反复顶电流上限
  => "看起来快，实际不划算"

安全修复：注入结束时新增 ramp_down_s=2.0s 斜坡淡出
  - 修复前：偏移阶跃归零 -> 云台高速回退（kp=35 时达 15.75 rad/s）= 失控旋转
  - 修复后：回退速度上限约 0.225 rad/s，三组实测 0.04~1.03 rad/s，无失控

注意：本批数据 /gimbal/yaw/temperature 恒为 125.0（22000 样本零变化）
      是温度反馈异常（int8 哨兵值），非真实过热（力矩全程仅 -0.09~-0.78 N·m）
      建议现场触摸 yaw 电机确认
